# Forest scenes: catalogue

Generated by scripts/forest-catalog.py. Do not edit by hand.

Every plant, animal and effect the sign-in scenes draw, and the code that draws it. Rebuild with `uv run python scripts/forest-catalog.py`. To see them, run the forest studio (`uv run python scripts/forest-studio.py`): it draws every element from the code in light and dark, beside the live scene.

## Reading the tables

- **Widths.** Counts come from `generate()` at 90, 160 and 240 px wide (a phone, a laptop and a wide monitor) with a fixed seed. A real page uses a random seed, so counts vary a little.
- **First stage.** A plant with `born` value b first shows at stage b + 1, and stage 0 is bare soil. An animal's first stage is the first stage at which a 60-second run of that stage, in a real Forest, shows it. Effects the run cannot see take the stage their code gates on.
- **Layer.** Plants are far, middle or near (the palettes fade the far rows). Animals and effects are drawn in front of the plants (`draw`) or behind them (`drawBack`).
- **Poses.** The names after an animal or effect are its sprites in the studio, drawn with a plausible object: walkers on the ground line, birds at a fixed height. The whale is drawn over the sea band it surfaces in. Falling leaves and petals are a hand-placed cluster of the one-pixel dots the code draws.
- **Timed effects.** The whale surfaces for about 3 seconds at a time, every 12 to 20 seconds, and walker and bird arrivals are random. A single sample can miss them.
- **Walkers on load.** A walker comes in from a screen edge when its stage is watered. When a scene is loaded, switched or resized, about half the walkers start somewhere on the page instead, and a young animal always starts just behind its parent.
- **Not catalogued.** The soil and its turf (`soil()`), and the fountain on the water canvas, which the user makes by clicking.
